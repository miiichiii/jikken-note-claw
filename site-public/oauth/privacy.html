プライバシーポリシー

最終更新日：2026年8月28日

Clawdbot Gmail（以下「本アプリ」）は、アプリ所有者本人のみが使用するGoogle CalendarおよびGmailの自動化アプリです。本ポリシーは、本アプリがGoogleユーザーデータをどのように取り扱うかを説明します。

取得・利用する情報

本人が許可した範囲で、Google Calendarの予定情報、およびGmailのメッセージ、スレッド、下書きにアクセスすることがあります。これらは、予定確認、リマインダー、メール要約、返信下書きなど、本人が依頼または設定した機能を実行する目的に限って利用します。

保存

OAuth認証情報と処理に必要な運用データは、所有者が管理する端末または所有者が管理する保存先に保持されます。処理結果、下書き、通知履歴などは、本人が依頼した機能の提供、重複防止、障害調査に必要な範囲で保存されることがあります。

外部サービスによる処理

Googleユーザーデータを販売したり、広告目的に使用したりしません。本人が依頼または設定した要約、下書き、予定確認、通知などの機能を実行するため、必要な範囲の情報が、本人が選択または設定したAI・自動化・通知サービスへ処理のために送信されることがあります。これらのサービスは、各サービスの利用規約およびプライバシーポリシーに従ってデータを取り扱います。それ以外に、本人の指示なくGoogleユーザーデータを第三者へ提供しません。

安全管理

アクセス権限は機能に必要な範囲に限定し、認証情報を公開しません。本人はGoogleアカウントのセキュリティ設定から本アプリのアクセスをいつでも取り消せます。

Google API Services User Data Policy

本アプリによるGoogle APIから受け取った情報の利用は、Google API Services User Data Policy（Limited Use要件を含む）に従います。

お問い合わせ

本アプリに関する問い合わせは、Google OAuth同意画面に表示されるユーザーサポート連絡先へお送りください。
